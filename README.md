# 🏥 Healthcare Dataset Analysis

## 📌 Overview
This project focuses on exploring and analyzing healthcare data using Python. It involves data cleaning, preprocessing, and exploratory data analysis (EDA) to understand patient information, medical conditions, hospital admissions, billing amounts, and other healthcare-related attributes.

## 🛠️ Technologies Used
- **Python**
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical operations
- **Jupyter Notebook** – Interactive data analysis

## 📊 Key Features
- Data inspection and exploration
- Handling missing values and duplicate records
- Data type conversion and preprocessing
- Analysis of patient demographics and medical conditions
- Exploration of billing amounts and admission types
- Date-based analysis using admission and discharge dates
- Creation of new columns using Pandas

## 🎯 Objectives
- Improve practical Python data analysis skills
- Learn data cleaning and preprocessing techniques
- Extract meaningful insights from healthcare data
- Develop a foundation in Exploratory Data Analysis (EDA)

## 🚀 Getting Started

Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Install the required libraries:

```bash
pip install pandas numpy jupyter
```

Open Jupyter Notebook and run the analysis.

## 📚 Learning Outcomes
This project demonstrates practical knowledge of Python, Pandas, NumPy, data preprocessing, and exploratory data analysis.
